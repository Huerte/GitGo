# GitGo CLI Privacy Policy

GitGo CLI is an open-source command-line tool for Git workflow management.

## Data Collection
GitGo does not intentionally collect or transmit personal information to a GitGo-operated server unless a specific feature explicitly implements such functionality.

## Local Data
GitGo may read or modify local project files and Git repository data as required by the commands you execute. Configuration files and saved snapshots may be stored locally.

## Third-Party Services
GitHub-related features may communicate with GitHub using the authentication method configured by the user. GitHub's own privacy policy and terms apply to its services.

## Credentials
Users should protect authentication tokens and other credentials. Never share credentials publicly or commit them to a repository.

## Open Source
GitGo's source code is publicly available at https://github.com/Huerte/GitGo.

## Contact
For questions or privacy concerns, open an issue at https://github.com/Huerte/GitGo/issues.
